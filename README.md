# Acer's website

A small personal website hosted on GitHub Pages.

## Try it locally

Open `index.html` in your browser and click **Say hello**. No installation or build step is needed.

## How it works

Everything is in `index.html`:

- HTML defines the headings, paragraphs, and button.
- CSS inside `<style>` controls colors, spacing, and layout.
- JavaScript inside `<script>` changes the message when you click the button.

Edit some text, save the file, and refresh your browser to see the change.

## Publish on GitHub Pages

Commit and push the files to `acercyc/acercyc.github.io`. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, and save. Once GitHub finishes publishing, visit https://acercyc.github.io/.

Local edits do not change the public site until they are committed, pushed, and deployed.
